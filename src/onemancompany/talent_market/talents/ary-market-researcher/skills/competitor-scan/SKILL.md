# 競爭對手掃描 SOP

## 開始前確認
1. 是 UZENA 還是 GWIs？比較哪一類產品？
2. 要比幾家？（預設 5 家）地區？（預設墨爾本／維州，可擴到全澳）

## 步驟
1. 先讀自家官網（uzena.com.au 或 gwifruits.com），寫 3 行「我們是誰、賣什麼、賣給誰」。
2. 用 web_search 找競爭者：關鍵字組合「產品 + Melbourne / Victoria / Australia」「產品 + online / wholesale」，至少換 3 組關鍵字。
3. 每家記錄：名稱、網址、主力產品、價格區間（AUD）、配送範圍、特色賣點、社群經營情況。
4. 做比較表，最後一欄寫「我們可以學／可以贏的地方」。
5. 自我檢查：
   - [ ] 每一列都有來源連結
   - [ ] 價格有註明查詢日期
   - [ ] 推論有標明是推論

## 交件格式
```
## 結論（3 句）
## 比較表
## 機會與威脅（各 3 點）
## 來源（含查詢日期）
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 每個數字有來源連結＋查詢日期
- [ ] 貨幣 AUD、地區註明
- [ ] 推論已標明，有信心程度
- [ ] 打不開／查不到的已照實寫出
- [ ] 結論先行、有比較表

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
