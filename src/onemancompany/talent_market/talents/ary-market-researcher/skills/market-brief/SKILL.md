# 市場簡報 SOP

## 步驟
1. 把問題改寫成 1 句研究問題，例如「墨爾本年輕家庭買水果禮盒的主要考量是什麼？」。
2. 優先找可信來源：政府統計（ABS https://www.abs.gov.au/）、產業協會、主流媒體、上市公司報告。
3. 整理：市場大小／成長、主要客群、購買通路、趨勢、法規注意點（交給維州法規助理深入）。
4. 最後給 3 個可以馬上做的行動建議。

## 交件格式
```
## 一句話答案
## 重點發現（5 點以內，每點附來源）
## 行動建議（3 點）
## 資料限制
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 每個數字有來源連結＋查詢日期
- [ ] 貨幣 AUD、地區註明
- [ ] 推論已標明，有信心程度
- [ ] 打不開／查不到的已照實寫出
- [ ] 結論先行、有比較表

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
