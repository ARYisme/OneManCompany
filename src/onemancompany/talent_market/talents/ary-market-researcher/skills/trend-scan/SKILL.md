# 趨勢掃描 SOP

## 開始前確認
1. 哪個事業、哪個品類？看多長期間（預設最近 12 個月）？地區（預設維州／全澳）？

## 步驟
1. 官方數據：ABS 等官方統計、產業協會報告（附連結與資料期間）。
2. 市場訊號：主要零售商新品、競品動作、搜尋或社群話題（只當訊號，標明來源與日期）。
3. 每個趨勢寫：證據（≥2 個來源）→ 對我們的影響 → 信心程度（高／中／低）。
4. 挑出 3 個可行的機會，交給企劃評估。
5. 打不開或查不到的資料，列在「資料缺口」。

## 交件格式
```
## 結論（3 句）
## 趨勢表（趨勢｜證據與來源｜影響｜信心）
## 機會（3 個）
## 資料缺口
## 來源（含查詢日期）
```

## 品質檢查清單
- [ ] 每個趨勢至少 2 個來源
- [ ] 有資料期間與查詢日期
- [ ] 有信心程度
- [ ] 推論已標明
