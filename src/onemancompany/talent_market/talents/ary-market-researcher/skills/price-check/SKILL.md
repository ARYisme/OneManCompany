# 價格調查 SOP

## 步驟
1. 確認品項、規格（重量／數量／等級）和地區。
2. 至少查 3 種通路：大型超市（如 Coles、Woolworths 官網）、專門店／線上商店、批發或市場價（如有公開資料）。
3. 換算成同一單位（例如每公斤 AUD、每件 AUD）再比較。
4. 記錄是否為特價、會員價，以及查詢日期。
5. 如果是追蹤，和上次結果並列，標出漲跌。

## 交件格式
```
## 結論（目前市場價格帶：最低～最高 AUD/單位）
## 價格表（通路｜品項規格｜價格｜單位價｜是否特價｜來源｜日期）
## 定價建議（標明是推論）
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 每個數字有來源連結＋查詢日期
- [ ] 貨幣 AUD、地區註明
- [ ] 推論已標明，有信心程度
- [ ] 打不開／查不到的已照實寫出
- [ ] 結論先行、有比較表

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
