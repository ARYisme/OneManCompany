# 給老闆的摘要 SOP（SCQA）

## 步驟
1. 讀完全部資料，標出關鍵數字與決策點。
2. 用 SCQA 排：情況（現在怎樣）→ 問題（卡在哪）→ 問題本身（要決定什麼）→ 答案（建議）。
3. 重點 3～5 個，每個至少一個數字或比較，並附原文出處（哪份文件、哪一段）。
4. 建議 2～4 個，每個寫「誰、做什麼、何時」。
5. 資料缺口與不確定的地方另外列出；不要自己補。
6. 全文 300～500 字。

## 交件格式
```
## 一句話結論
## 情況與問題
## 重點（3～5，附出處）
## 建議與下一步（誰／做什麼／何時）
## 資料缺口
```

## 品質檢查清單
- [ ] 500 字以內
- [ ] 每個重點有數字或比較，並有出處
- [ ] 沒有加入原資料沒有的事實
- [ ] 待辦都有負責人和日期
