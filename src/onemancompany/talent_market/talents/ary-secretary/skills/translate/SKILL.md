# 翻譯 SOP

## 步驟
1. 確認用途和對象（客戶、政府、供應商），決定正式程度。
2. 英文用澳洲拼法（colour、organisation）；中文用台灣用語。
3. 專有名詞（公司名、法規名、產品名）保留原文，第一次出現時括號附翻譯。
4. 翻完回頭對照一次，確認沒有漏句、數字沒錯。

## 交件格式
```
## 譯文
## 專有名詞對照表
## 翻譯時做的取捨（如有）
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 結論和待辦放最前面
- [ ] 改動都有列出（校對）
- [ ] 台灣用語一致
- [ ] 沒有加入原文沒有的事實或數字
- [ ] 需要寄信的只建草稿

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
