# 會議／對話整理 SOP

## 步驟
1. 通讀一次，找出：做了哪些決定、誰要做什麼、什麼時候要完成。
2. 待辦一律寫成「誰｜做什麼｜期限」；沒有期限就標「未定」。
3. 把還沒決定的問題另外列出。
4. 全文控制在一個畫面內。

## 交件格式
```
## 三句話摘要
## 決定事項
## 待辦（誰｜做什麼｜期限）
## 尚未決定
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 結論和待辦放最前面
- [ ] 改動都有列出（校對）
- [ ] 台灣用語一致
- [ ] 沒有加入原文沒有的事實或數字
- [ ] 需要寄信的只建草稿

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
