# 校對審稿 SOP

## 步驟
1. 錯字與標點（全形標點用於中文）。
2. 用語：把簡體字和中國用語改成台灣用語（例：軟件→軟體、數據→資料（視上下文）、視頻→影片、質量→品質）。
3. 事實：數字、日期、價格前後是否一致；有沒有缺來源。
4. 易讀：段落太長就拆，結論放最前面。
5. 列出所有修改（原文→改後→原因）。

## 交件格式
```
## 修改後全文
## 修改清單（原文｜改後｜原因）
## 需要原作者確認的地方
```
