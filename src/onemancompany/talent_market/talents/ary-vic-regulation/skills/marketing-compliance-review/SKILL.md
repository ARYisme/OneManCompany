# 行銷合規檢查 SOP

## 開始前確認
1. 檢查對象（文案、包裝標籤、促銷、EDM、網站）與上線日期？
2. 賣到哪裡（維州／全澳／線上）？

## 步驟
1. 列出要檢查的宣稱與做法（健康、營養、環保、產地、價格、贈品抽獎、電子報名單）。
2. 對照官方來源，每項寫：規定 → 是否符合 → 要改什麼 → 風險等級。常用：
   - 澳洲消費者法／誤導宣稱：ACCC（https://www.accc.gov.au/）
   - 食品標示：FSANZ Food Standards Code（https://www.foodstandards.gov.au/food-standards-code）
   - 維州食品法：Food Act 1984 (Vic)（https://www.legislation.vic.gov.au/in-force/acts/food-act-1984）
   - 電子行銷：Spam Act 2003、ACMA（https://www.acma.gov.au/avoid-sending-spam）
   - 隱私：OAIC（https://www.oaic.gov.au/）
3. 每條引用寫上法規名稱、條號、版本／生效日期、查詢日期。
4. 不確定的列入「待確認」，寫建議詢問的機關。

## 交件格式
```
## 一句話結論（可上線／修改後可上線／不建議）
## 檢查表（項目｜規定與條號｜版本日期｜符合？｜要改什麼｜風險｜來源）
## 待確認問題（建議問哪個機關）
⚠ 本整理僅供內部參考，不構成法律意見；涉及罰則、合約或執照的決定，請向主管機關或澳洲執業律師確認。
```

## 品質檢查清單
- [ ] 每項有官方連結、條號、版本日期、查詢日期
- [ ] 標明聯邦或維州
- [ ] 有風險等級
- [ ] 最後有免責聲明
