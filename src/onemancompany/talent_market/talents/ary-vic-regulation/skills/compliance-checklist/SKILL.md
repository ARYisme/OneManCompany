# 上線前合規檢查清單 SOP

## 步驟
1. 寫下這次要做的事（例：GWIs 推出水果禮盒線上販售、配送到全維州）。
2. 逐項檢查並標「符合／待處理／不適用」：
   - 消費者法：價格標示、促銷條件、退換貨（消費者保障不可排除）、不實宣稱（ACCC）。
   - 食品：營業註冊（維州地方政府／衛生部）、標示與原產地標示（FSANZ、ACCC）、過敏原、保存溫度。
   - 植物檢疫：跨州運送水果的限制（如果蠅管制區，Agriculture Victoria）。
   - 隱私與行銷：收集客戶資料的告知、電子報同意與取消訂閱（OAIC、ACMA）。
   - 稅務：GST 是否適用（ATO）。
3. 每個「待處理」寫出下一步和負責人。

## 官方來源（優先用這些，查到的內容要附「實際頁面」連結）
- 澳洲聯邦法規全文：https://www.legislation.gov.au/
- 維州法規全文：https://www.legislation.vic.gov.au/
- 消費者法（ACL）：https://www.accc.gov.au/ 、https://consumerlaw.gov.au/
- 維州消費者事務局：https://www.consumer.vic.gov.au/
- 食品標準（FSANZ，含標示、Food Standards Code）：https://www.foodstandards.gov.au/
- 維州衛生部食品安全（Food Act 1984 (Vic)、註冊分級）：https://www.health.vic.gov.au/
- 維州農業部（植物檢疫、果蠅、園藝）：https://agriculture.vic.gov.au/
- 聯邦農業部（進出口、生物安全）：https://www.agriculture.gov.au/
- 隱私（OAIC）：https://www.oaic.gov.au/
- 垃圾訊息／電子行銷（ACMA）：https://www.acma.gov.au/
- 公司／稅務：https://asic.gov.au/ 、https://www.abr.gov.au/ 、https://www.ato.gov.au/
- 僱用：https://www.fairwork.gov.au/ 、職安 https://www.worksafe.vic.gov.au/

## 交件格式
```
## 結論（可以上線／處理完 X 項後可上線）
## 檢查清單表格（項目｜狀態｜說明｜官方連結）
## 待處理事項
⚠ 本整理僅供內部參考，不構成法律意見；涉及罰則、合約或執照的決定，請向主管機關或澳洲執業律師確認。
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 只用官方來源當依據
- [ ] 每點有法規名稱／條號、版本或生效日期、查詢日期
- [ ] 標明聯邦或維州
- [ ] 有風險等級與待確認問題
- [ ] 最後有「不構成法律意見」免責聲明

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
