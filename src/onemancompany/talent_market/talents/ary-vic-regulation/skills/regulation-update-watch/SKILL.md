# 法規變動追蹤 SOP

## 步驟
1. 確認範圍（例：食品標示、消費者法、維州食品註冊）和期間（預設最近 3 個月）。
2. 搜尋主管機關的新聞稿／更新頁面（ACCC、FSANZ、維州衛生部、Agriculture Victoria、OAIC）。
3. 只列「已公告」的變動，草案或諮詢中的另外標明。
4. 每項寫：生效日、影響誰、我們要不要做什麼。

## 交件格式
```
## 這期重點（3 點以內）
## 變動清單（日期｜機關｜內容｜對我們的影響｜連結）
⚠ 本整理僅供內部參考，不構成法律意見；涉及罰則、合約或執照的決定，請向主管機關或澳洲執業律師確認。
```
