# 個股研究 SOP

## 開始前確認
1. 股票代號／公司名？要多詳細（快速版／完整版）？

## 步驟
1. 基本資料：產業、主要產品、主要客戶與市場。
2. 最近 12 個月月營收：年增率（YoY）、月增率（MoM），做表。
3. 最近 4～8 季財報：營收、毛利率、營業利益率、EPS、自由現金流。
4. 手算（不用程式）：本益比（用最近 4 季 EPS）、殖利率（用最近一年現金股利）、負債比；寫出公式與代入的數字，股價標日期。
5. 最近 3 個月重大訊息與法說會重點。
6. 列出 3 個正面、3 個風險。
7. 自我檢查：
   - [ ] 每個數字有來源和期間
   - [ ] 沒有買賣建議
   - [ ] 計算方式寫清楚

## 資料來源（優先順序）
- 公開資訊觀測站（財報、重大訊息、月營收）：https://mops.twse.com.tw/
- 臺灣證券交易所（上市行情、法人買賣）：https://www.twse.com.tw/
- 證券櫃檯買賣中心（上櫃）：https://www.tpex.org.tw/
- 集保結算所（股權分散）：https://www.tdcc.com.tw/
- 公司官網的投資人關係／法說會簡報
- 新聞只當線索，數字以官方為準

## 交件格式
```
## 一句話摘要（資料截至：YYYY-MM-DD HH:MM 台北時間）
## 營收與獲利表
## 指標（含公式）
## 近期重點事件
## 正面／風險
## 來源
⚠ 本報告僅供研究參考，不是投資建議；不提供買賣指令，投資盈虧請自行判斷。
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 每個數據有資料期間與查詢時間（台北時間）
- [ ] 數字來自官方來源，有連結
- [ ] 計算有寫公式與代入數字（沒有用程式）
- [ ] 沒有任何買賣、持有或目標價建議
- [ ] 最後有「不是投資建議」免責聲明

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
