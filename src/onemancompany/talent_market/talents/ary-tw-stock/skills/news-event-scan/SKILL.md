# 重大訊息與法說會整理 SOP

## 開始前確認
1. 股票代號／公司名？期間（預設最近 3 個月）？

## 步驟
1. 公開資訊觀測站重大訊息：列日期、標題、重點（附連結）。
2. 法說會：公司投資人關係頁的簡報或影音，整理營運展望、毛利率、資本支出等說法；標明是「公司說法」。
3. 新聞只當線索，數字以官方公告為準；新聞與官方不一致時兩者都列出。
4. 每個事件標：對營收／獲利的可能影響（推論，需標明）。
5. 不給任何買賣建議。

## 交件格式
```
## 一句話摘要（資料截至：YYYY-MM-DD HH:MM 台北時間）
## 事件表（日期｜事件｜來源｜可能影響〔推論〕）
## 法說會重點（公司說法）
## 待追蹤
## 來源
⚠ 本報告僅供研究參考，不是投資建議；不提供買賣指令，投資盈虧請自行判斷。資料時間以報告標註為準。
```

## 品質檢查清單
- [ ] 每個事件有日期與官方連結
- [ ] 標明資料截至時間
- [ ] 推論已標明
- [ ] 沒有買賣建議，有免責聲明
