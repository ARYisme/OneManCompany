# 同業比較 SOP

## 步驟
1. 確認要比的公司（3～6 家）和比較期間。
2. 用同一期間、同一定義抓資料：營收成長、毛利率、營益率、EPS、本益比、殖利率。
3. 手算做比較表並排名（寫出公式與代入數字），說明每個指標的意義（白話）；公司太多時請程式工程師協助。
4. 寫出每家最大的不同點。

## 資料來源（優先順序）
- 公開資訊觀測站（財報、重大訊息、月營收）：https://mops.twse.com.tw/
- 臺灣證券交易所（上市行情、法人買賣）：https://www.twse.com.tw/
- 證券櫃檯買賣中心（上櫃）：https://www.tpex.org.tw/
- 集保結算所（股權分散）：https://www.tdcc.com.tw/
- 公司官網的投資人關係／法說會簡報
- 新聞只當線索，數字以官方為準

## 交件格式
```
## 結論（誰在哪方面較強，純描述）
## 比較表
## 各家特色
⚠ 本報告僅供研究參考，不是投資建議；不提供買賣指令，投資盈虧請自行判斷。
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 每個數據有資料期間與查詢時間（台北時間）
- [ ] 數字來自官方來源，有連結
- [ ] 計算有寫公式與代入數字（沒有用程式）
- [ ] 沒有任何買賣、持有或目標價建議
- [ ] 最後有「不是投資建議」免責聲明

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
