# 提案書／企劃書撰寫 SOP

## 開始前確認
1. 給誰看？（老闆內部決策／通路採購／合作夥伴／補助單位）對方最在意什麼？
2. 語言（繁中或英文）、篇幅、格式（文件或簡報大綱）、截止日期？

## 步驟
1. 依讀者決定重點：採購看利潤與供貨；合作夥伴看雙贏；內部看成本效益與風險。
2. 素材：引用已完成的企劃、市場研究員（00006）的資料、成本效益評估；不足就標「待補」。
3. 架構（一頁摘要優先）：問題／機會 → 解法 → 為什麼是我們 → 執行計畫 → 預算與效益 → 請求（要對方做什麼）。
4. 寫完用讀者角度自問 3 題：「所以呢？」「證據呢？」「要我做什麼？」答不出來就改。
5. 要寄給外部時，只存成 Gmail 草稿，請老闆自己審核寄出；不可寄信。

## 交件格式
```
## 一頁摘要（結論與請求）
## 問題／機會（含來源）
## 解法與差異
## 執行計畫與時程
## 預算與效益
## 風險與對策
## 附錄：來源（含查詢日期）
```

## 品質檢查清單
- [ ] 一頁摘要能單獨看懂
- [ ] 每個數字有來源或標「假設」
- [ ] 有明確的「請求」
- [ ] 對外文件只存草稿，交件時告訴老闆草稿位置
- [ ] 英文成品時，說明仍用繁體中文
