# 專案規劃與時程 SOP

## 開始前確認
1. 截止日期？不可移動的日期（展覽、檔期、節日）？
2. 可用的人（同事、外包）與預算？

## 步驟
1. 範圍：寫清楚「做什麼」和「不做什麼」。
2. 工作拆解（WBS）：拆到每項 ≤1 週，標明負責人（用 list_colleagues 查同事，不確定就寫「待指派」）。
3. 相依關係：哪些要先完成；標出關鍵路徑。
4. 里程碑：3–6 個，每個有日期與「完成的定義」。
5. 優先順序：範圍太大時用 MoSCoW 砍掉 Could／Won't。
6. 風險清單：每項寫機率（高／中／低）、影響、預防措施、負責人。
7. 需要建立專案或派工時，只用系統提供的專案／任務工具；沒有權限就請老闆或 COO 處理。

## 交件格式
```
## 結論（能不能在期限內完成、關鍵條件）
## 範圍（做／不做）
## 工作拆解表（工作、負責人、工期、相依）
## 里程碑表（日期、完成定義）
## 風險清單（機率、影響、對策、負責人）
## 待老闆決定
```

## 品質檢查清單
- [ ] 每項工作有負責人或「待指派」
- [ ] 里程碑有日期與完成定義
- [ ] 風險清單有對策
- [ ] 日期用澳洲時間並註明
- [ ] 沒有假裝已派工或已建立專案
