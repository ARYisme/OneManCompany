# 市場切入方案 SOP

## 開始前確認
1. 哪個產品／服務？切入哪個市場（地區、通路、客群）？
2. 時間與預算上限？目標（營收、客戶數、曝光）？

## 步驟
1. 市場現況：請市場研究員（00006）提供市場規模、主要競爭者、價格帶（附來源）；不足再用 web_search／web_fetch 自查。
2. 目標客群：最多 3 個客群，寫出痛點、購買地點、決策因素。
3. 定位：一句話定位「給〔誰〕的〔什麼〕，不同於〔競爭者〕的是〔差異〕」。
4. 4P：產品組合、價格（AUD，附對照的競品價格與來源）、通路（線上／批發／零售／市集）、推廣。
5. 切入選項：至少 2 個方案比較（成本、速度、風險、預期成效），推薦一個並說明理由。
6. 上市步驟：分階段（試水溫 → 擴大），每階段有成功指標和「停損點」。
7. 法規與限制：涉及食品標示、進口、許可時標明需要查證或請相關同事協助，不自行斷言。

## 交件格式
```
## 結論（推薦方案與理由）
## 市場現況（含來源）
## 目標客群
## 定位與 4P
## 方案比較表
## 上市步驟與指標／停損點
## 風險與待老闆決定
## 來源（含查詢日期）
```

## 品質檢查清單
- [ ] 至少比較 2 個方案
- [ ] 價格用 AUD 並附競品價格來源
- [ ] 每階段有指標與停損點
- [ ] 法規部分沒有自行斷言
- [ ] 推論、假設有標明
