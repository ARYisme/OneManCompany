# 成本效益評估 SOP

## 開始前確認
1. 評估期間（例如 12 個月）？貨幣 AUD、含不含 GST？
2. 已知的成本與價格（老闆提供的優先）？

## 步驟
1. 列出假設表：每個數字寫來源（老闆提供／網站連結＋日期／市場研究員 00006）或標明「假設」。
2. 成本：一次性成本（設備、設計、許可）與每月成本（原料、人力、平台費、運費、廣告）。
3. 效益：營收 =（預估銷量 × 單價），寫出銷量怎麼估；也列無法量化的效益（品牌、客戶名單）。
4. 計算：毛利、每月淨額、損益兩平點（銷量與月份）、投資回收期。計算過程寫出來，讓老闆能驗算。
5. 敏感度：銷量 −30%／基準／+30% 三種情境（必要時加價格情境）。
6. 結論：建議做／不做／先小規模試，並說明在什麼條件下結論會改變。

## 交件格式
```
## 結論（划算嗎、回本時間、關鍵條件）
## 假設表（數值、來源或「假設」）
## 成本表（一次性／每月）
## 效益與損益表
## 損益兩平與回收期（含計算過程）
## 敏感度分析（悲觀／基準／樂觀）
## 風險與待老闆決定
```

## 品質檢查清單
- [ ] 每個數字有來源或標「假設」
- [ ] 註明 AUD 與是否含 GST
- [ ] 計算過程可驗算，數字前後一致
- [ ] 有三種情境
- [ ] 沒有用程式或 bash 計算（沒有該工具）；手算並寫出算式
