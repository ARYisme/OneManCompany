# 電子報 SOP

## 步驟
1. 確認目的（促銷／新品／節日問候）、對象、寄送日期。
2. 寫 3 個主旨（Subject）選項，各 40 字元內，加 1 句預覽文字。
3. 內文結構：開場 1 句 → 重點 3 項 → 行動按鈕文字 → 簽名。
4. 頁尾提醒：必須有取消訂閱方式與寄件者身分（澳洲 Spam Act 要求，參考 https://www.acma.gov.au/）。
5. 只寫稿，不寄出；寄送由老闆決定。

## 交件格式
```
## 主旨選項（3 個）＋預覽文字
## 內文
## 按鈕文字
## 寄送前檢查清單
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 至少 2～3 個版本，並說明差別
- [ ] 品牌語氣與官網一致
- [ ] 已跑「宣稱檢查」（claims-check）
- [ ] 價格、日期都來自老闆資料
- [ ] 只寫稿／只建草稿，沒有寄出或發布

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
