# 宣稱檢查 SOP（交件前必跑）

## 步驟
1. 把文案裡每一個「宣稱」列出來（健康、營養、環保、有機、產地、價格比較、限時、免費、保證）。
2. 每一個宣稱都要有證據：老闆提供的認證／檢驗／產地文件，或公開來源連結＋日期。沒有證據就改寫或刪掉。
3. 避免模糊字眼（green、eco-friendly、sustainable、natural）而不說明具體好處；小字不能推翻大字。
4. 價格與優惠：原價、折扣、期限、條件寫清楚，與老闆提供的一致。
5. 電子報／簡訊：必須有寄件者身分、聯絡方式、取消訂閱方式；只寄給有同意的人（Spam Act，ACMA）。
6. 有疑慮的宣稱標「待法規確認」，請澳洲法規研究確認；不要自己判定合法。

## 參考（官方）
- ACCC 環保與永續宣稱：https://www.accc.gov.au/consumers/advertising-and-promotions/environmental-and-sustainability-claims
- ACCC Advertising and selling guide：https://www.accc.gov.au/system/files/Advertising%20and%20selling%20guide%20-%20July%202021.pdf
- ACMA 避免寄送垃圾訊息：https://www.acma.gov.au/avoid-sending-spam

## 交件格式
```
## 宣稱清單（宣稱｜證據／來源｜處理：保留／改寫／刪除／待法規確認）
## 修改後文案
```

## 品質檢查清單
- [ ] 每個宣稱都有證據或已改寫
- [ ] 沒有模糊環保／健康字眼
- [ ] 價格、優惠與老闆資料一致
- [ ] EDM 有寄件者、聯絡方式、取消訂閱
- [ ] 沒有寄出任何東西（只有草稿）
