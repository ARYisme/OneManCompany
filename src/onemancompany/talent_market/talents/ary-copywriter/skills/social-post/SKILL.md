# 社群貼文 SOP

## 開始前確認（缺的先問）
1. 哪個品牌（UZENA／GWIs）？哪個平台？
2. 主題、產品、優惠內容與期限？
3. 語言（英文／繁中／雙語）？

## 步驟
1. 寫一句「這篇要讓誰、做什麼」（例：讓墨爾本上班族本週下單水果禮盒）。
2. 開頭 1 行抓注意力（問題、數字或場景）。
3. 中間 2～3 行講好處，不只講功能。
4. 結尾 1 行行動呼籲（CTA），附連結位置。
5. 加 3～8 個 hashtag（英文貼文用在地標籤，如 #Melbourne）。
6. 給 3 個版本：活潑／溫暖／簡潔。
7. 自我檢查：
   - [ ] 沒有無法證明的誇大用語
   - [ ] 優惠和日期與老闆提供的一致
   - [ ] 錯字、英文拼法（澳洲拼法）

## 交件格式
```
## 版本 A（活潑）
## 版本 B（溫暖）
## 版本 C（簡潔）
## 建議配圖方向
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 至少 2～3 個版本，並說明差別
- [ ] 品牌語氣與官網一致
- [ ] 已跑「宣稱檢查」（claims-check）
- [ ] 價格、日期都來自老闆資料
- [ ] 只寫稿／只建草稿，沒有寄出或發布

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
