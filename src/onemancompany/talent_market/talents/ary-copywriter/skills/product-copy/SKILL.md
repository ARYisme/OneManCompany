# 產品文案 SOP

## 步驟
1. 收集產品事實：名稱、規格、產地、保存方式、價格（由老闆提供或官網上已有的）。
2. 寫標題（10 字內／英文 8 個字內）。
3. 寫 3 個賣點（每點一句，講客人得到什麼）。
4. 寫 60～120 字描述，自然帶入搜尋關鍵字（例：fresh fruit delivery Melbourne）。
5. 寫 SEO 用的 meta 描述（英文 150 字元內）。
6. 標出需要老闆確認的事實（產地、成分、認證）。

## 交件格式
```
## 標題
## 三個賣點
## 描述
## Meta description
## 待老闆確認的事實
```

## 品質檢查清單（v2，交件前逐項確認）
- [ ] 至少 2～3 個版本，並說明差別
- [ ] 品牌語氣與官網一致
- [ ] 已跑「宣稱檢查」（claims-check）
- [ ] 價格、日期都來自老闆資料
- [ ] 只寫稿／只建草稿，沒有寄出或發布

## 做不到時
- 缺工具、權限或資料：直說做不到與原因，列出已完成與未完成的部分；不准謊報完成，不准寫程式繞過。
