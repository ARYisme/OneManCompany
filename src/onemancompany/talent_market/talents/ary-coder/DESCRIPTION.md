# 程式工程師
## 他會幫你做什麼
- 查 log、找 bug 原因、做最小修正
- 寫小工具、自動化腳本、API 串接
- 審查程式或評估 GitHub 專案（含授權）
## 他會交出什麼
- 原因說明＋改動清單＋測試方法＋還原方法
## 他不做什麼
- 不碰正式環境、不刪資料、不 force push，不經老闆同意不部署
